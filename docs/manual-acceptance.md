# 真实 Chrome 发布验收清单

本文件是待执行的验收计划，未勾选项目均为待验收，不代表已经通过。自动化及已执行集成测试的实际结果单独记录于 [测试报告](test-report.md)。完整通过标准见规格第 14–16 节。

## 环境与记录

- [ ] 最低支持 Chrome 120：记录完整版本、操作系统与机器配置，执行核心用例。
- [ ] 发布时 Chrome 稳定版 macOS：记录完整版本，执行核心用例及真实拖拽/折叠。
- [ ] 发布时 Chrome 稳定版 Windows：记录完整版本，执行核心用例及真实拖拽/折叠。
- [ ] 记录扩展版本、构建版本、日期、步骤、预期/实际结果、耗时和浏览器 API 写入次数；失败附可复现步骤。
- [ ] 真实 Salesforce 场景仅使用授权测试 org；其余 URL 用虚构 fixtures，不在截图或日志保留凭证及客户信息。

最低版与两个操作系统的结果必须分别记录。Playwright Chromium、mock、手动终止 worker 均不能替代真实 Chrome session restore 或关闭 DevTools 后的自然休眠。

## 自动分组与用户保护

- [ ] **AC-01/02**：首次安装前准备 3 个普通窗口、60 个受支持非 pinned 未分组标签页和 20 个其他网页；从未打开 popup 即按 window/tenant 收敛。禁用后重新启用也自动扫描。
- [ ] **AC-03/14**：Chrome 真正退出并恢复窗口，持续 60 秒分批恢复标签页；验证后台窗口、discarded tabs、保存组恢复及 group ID 变化。纯名称组在会话绑定丢失后保持原状，不凭名称接管；旧版标记组通过登记和成员验证迁移，未读到 URL 时保持恢复中，歧义组受保护。
- [ ] **AC-04/05**：新建、普通网页→Salesforce、tenant A→B、Lightning↔Setup↔My Domain；同 tenant surface 切换不重建组。受管页导航出 Salesforce 后退出，用户组中的页面保持原组。
- [ ] **AC-06/08**：同名用户组、其他扩展组、未知恢复组不被接管；标题、颜色、折叠、组内及整组顺序不被反复覆盖。纯名称组通过会话绑定识别，可改名/改色；旧标记迁移后不再显示，复制旧标记或混入其他 tenant 后保守保护。
- [ ] **AC-07**：pinned 全程不被取消，unpin 后重新评估。活动页加入折叠目标组时可见，active tab 和窗口焦点保持；没有自动导航、刷新、关闭、复制或跨窗口搬动。
- [ ] **AC-09**：手动取消分组、拖入用户组或其他 tenant 管理组后，重复事件、alarm、worker 重启不抢回；设置中的「恢复自动管理」生效。浏览器重启后 session override 可消失，local tenant 排除仍保留。
- [ ] **AC-10**：单 tab 与整组跨窗口拖拽、同时导航/关闭、tab replacement、关闭组/窗口；不拉回、不使用失效 ID、不留下未处理错误。拖拽期间 API 拒绝后可恢复。
- [ ] **AC-11**：开关默认开启；关闭保留现有组且无后续新自动动作，重开全量整理并保留 tenant 排除。禁用、更新、reload 不重置本地偏好。
- [ ] **AC-12**：同窗口同时新增 30 个同 tenant 标签页最终只有一个管理组；稳定后 100 次重复事件没有分组/取消分组/外观写入。
- [ ] **AC-13**：普通域环境为 unknown；标准 Experience Cloud 与同 tenant 合组，自定义/旧站点域、共享登录入口、欺骗 host 保持原状。隐身、非普通窗口、shared group、Split View 均跳过且说明原因。

## 生命周期、故障与主动切换

- [ ] 关闭 service worker DevTools，等待真实自然休眠，再通过新建/导航唤醒；所有普通窗口继续协调，手动排除保留。
- [ ] 手动终止 worker；在创建组的各 storage/API 边界注入中断，恢复后只在 journal 与事实吻合时完成创建，歧义不盲目接管或重复建组。
- [ ] 模拟事件遗漏、短计时器丢失、alarm 延迟/丢失；在下一次实际 reconciliation alarm 执行后收敛。记录实际延迟，不把名义 1 分钟当实时保证。
- [ ] 模拟存储不可写、配额/权限失败、无效 schema 与 migration；停止自动变更，显示降级，保留原始数据。
- [ ] **AC-15**：目标 origins 必须同 tenant、surface 正确且无路径；缺失 surface 提示配置或明确选择首页。预览最终 URL 后主动切换当前页，production 每次确认；过期、页面或配置改变后拒绝旧预览。
- [ ] Switcher 清除敏感 query/hash；允许的命名 list view 参数保留；认证跳转、Experience Cloud 和未知路径不能直接保留路径。record 页面显示 ID/权限限制；切换不绕过用户组或 manual override。
- [ ] **AC-16**：检查 dist 的权限、资源、CSP 和网络日志；仅 tabs/tabGroups/storage/alarms，无内容注入、后端/遥测/认证请求、远程执行代码或含认证数据的日志。

- [ ] 5 窗口 500 tabs 初始扫描与必要分组目标 ≤ 10 秒，记录各窗口/tenant 数量与 API 写入数。
- [ ] 休眠、恢复延迟、alarm 延迟与 API 拒绝单独列出，附失败或偏差原因，不能用模拟计时替代真实测量。

## 界面与键盘

- [ ] 在真实 Chrome action 弹窗中验证默认与 production 核对步骤，400px 宽、最大约 600px 高时内容可读；长 URL、长目标名及展开状态详情可正常滚动，无横向溢出。
- [ ] 全程仅用 `Tab` / `Shift+Tab` / `Enter` / `Space` 操作：选择框保持原生方向键行为，预览不会直接导航，production 每次要求确认。
- [ ] `Esc` 优先关闭原生选择框菜单；编辑或核对时取消当前步骤并回到触发按钮；无待取消步骤时保留浏览器原生关闭弹窗行为。
- [ ] macOS 与 Windows 的中文输入法候选窗开启时，`Enter` 仅确认文字，`Esc` 仅取消组合，不意外保存、取消编辑或关闭弹窗；系统与浏览器快捷键照常工作。
- [ ] 键盘聚焦列表按钮、修改尚未保存的表单时触发后台分组；焦点和草稿不丢失。保存、取消、删除及恢复自动管理后焦点落点合理。
- [ ] 系统浅色/深色、高对比度、200% 缩放及减少动态效果设置下检查可读性；VoiceOver / NVDA 可区分不同 Org 的编辑/删除按钮，接收局部成功或错误提示，后台计数更新不过度播报。
